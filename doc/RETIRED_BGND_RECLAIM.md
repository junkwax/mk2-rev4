## What this is

`data/MK7MIL.LOD` packs 29 background payloads via `BBB>`. 11 of them
cannot be reached by any code path. Their blocks are in the video ROM of
every build. Removing the `BBB>` line stops LOAD2 packing them.

LOAD2 dedups identical source blocks across payloads onto a single SAG,
so a block a **live** background also declares survives the removal.
Only chunks exclusive to retired payloads disappear - **255,182 bytes**.

## How to remove

Delete the `BBB> <NAME>` line from `data/MK7MIL.LOD` and rebuild
(`python build.py`). Nothing else needs to change:

- **Do NOT touch `table_o_mods` in `src/BGND.ASM`.** It is indexed by
  `curback`; deleting an entry shifts every index after it and would
  repoint Outer Haven (16), FLAPJACK (17) and Yoteigai Tor (18).
- **Do NOT delete the sections from `src/BGNDTBL.ASM`.** The promoters
  classify a label missing from the snapshot as `src_only` and preserve
  it untouched, so the build stays quiet.

## Rollback

Restore the `BBB> <NAME>` line and rebuild. The payload is rebuilt from
the same BDB/BDD on disk, so nothing is lost by removing it - the art is
in `data/`, not only in the ROM.

**The hazard is a partial rollback.** After removal, the `*HDRS`
sections still sitting in `src/BGNDTBL.ASM` keep their last-known SAGs,
which now point at whatever moved into those addresses. That is inert
only while nothing can select the mod. If you ever re-enable
`the_story`, `advertise_comic` or `print_rankings`, **restore the
`BBB>` line first** or the screen decodes unrelated pixels - the exact
failure mode of the ACIDHANG hangers.

**On the Wolf board `the_story` and `show_next_bio` ARE live again**
(2026-10-10) - and they do NOT use these stale records. ATRAX1-4 and
STORY1 are re-packed above the T-unit's 12 MB by `data/WSTORY.LOD`, and
`tools/make_wolf_story.py` turns LOAD2's snapshot (`BGNDTBL.WST`) into
renamed W* copies in `src/WSTORY.ASM`; `one_story_screen` (MKAMODE.ASM)
takes those via `wstory_mods` under `.if wunit`. The T-unit stays as
above: still retired, still unreachable.

`python tools/retired_bgnd_audit.py --check` fails if a LIVE payload's
`BBB>` line ever goes missing.
