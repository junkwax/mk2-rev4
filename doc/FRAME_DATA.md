# MK2 frame data, extracted from source

Generated by `tools/frame_data.py`. Every value is read out of
MKSTK.ASM or a move handler - nothing is measured or estimated.

**Startup is not in this table.** The windup is `act_mframew`
playing an animation whose row count lives in the per-character
.TBL ani tables, indexed by a9. That is a separate parse and it is
left out rather than guessed.

**The two tables are not joined, on purpose.** A handler such as
`do_swipe` is Baraka-only; expanding handlers across all 17
characters invents rows like "do_swipe / jade / stk_spinfan".
Look a handler stk index up in the character you care about.
