# Retired video-ROM SAG ranges

Generated by `tools/map_retired_ranges.py` from `tmp/load2/BGNDTBL.MK7` stock MK7 LOAD2 snapshot.

Each row is one `BBB>` background payload in `data/MK7MIL.LOD`. Retired payloads have their runtime callers commented out per the Outer Haven postmortem — their SAG ranges are candidates for deliberate overlay by new content.

Addresses are TMS bit-addresses (the format `.long XXXXXXXXh` in `HDRS` sections). Chunk size is derived from the delta to the next SAG globally — this sidesteps zero-compression / `PPP>` bpp uncertainty (we never compute size from W×H).

To overlay a retired range, use `Start SAG`/`End SAG` as the runtime address window and `Flat start`/`Flat end` as the physical video-ROM window. The new payload must fit in `Size (bytes)`. For bank-1 LOAD2 sidecars, the `***>` directive is the raw LOAD2 address plus `,1`, not necessarily the runtime SAG; for example runtime `0x05e43418` uses `***> 3E43418,1`.
